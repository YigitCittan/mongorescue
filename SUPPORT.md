# Support

- **Questions and ideas:** ask in [GitHub Discussions](https://github.com/YigitCittan/mongorescue/discussions).
- **Documentation:** <https://yigitcittan.github.io/mongorescue/>
- **Bugs and feature requests:** open an issue with one of the [issue forms](https://github.com/YigitCittan/mongorescue/issues/new/choose). Include your version, install type and MongoDB version, and remove passwords from MongoDB URIs and logs first.
- **Security vulnerabilities:** never in a public issue. Follow [SECURITY.md](SECURITY.md).
