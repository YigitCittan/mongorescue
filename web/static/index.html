Download a recovery kit

No recovery kit has been downloaded since secret.key, the encryption keys or the storage targets last changed. Without secret.key a copy of the metadata database cannot be opened.

Metadata backups are not encrypted

Metadata backups are on but backup encryption is off, so snapshots are uploaded unencrypted. Turn encryption on in Settings → Encryption.
